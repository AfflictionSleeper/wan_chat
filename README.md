# WanChat

WanChat 是一个用于 B 站直播间弹幕显示的桌面悬浮弹幕工具。它可以把直播间弹幕以透明悬浮层的形式显示在屏幕上，并支持鼠标穿透、窗口编辑、字体/透明度调整、关键字屏蔽和用户 ID 屏蔽。

## 功能简介

- B 站直播间弹幕实时显示
- 透明悬浮弹幕幕布
- 穿透模式：鼠标可以操作幕布后面的桌面或软件
- 编辑模式：调整幕布位置和大小
- 弹幕字体大小、速度、透明度调节
- 弹幕关键字屏蔽
- 用户 ID 弹幕屏蔽
- HTML 字体标签支持，例如颜色和字号
- 弹幕文字带轻微黑色描边，提升浅色背景可读性

## 快速开始

### 运行已打包程序

双击运行：

```text
WanChat.exe
```

程序启动后会出现在系统托盘。右键托盘图标即可打开菜单。

### 从源码运行

安装依赖：

```bash
pip install -r requirements.txt
```

运行 Windows 版本：

```bash
python main.py
```

Linux/WSL 调试版本：

```bash
python main_wsl.py
```

## 打包程序

Windows 下直接双击：

```text
build.bat
```

打包完成后输出文件为：

```text
dist\WanChat.exe
```

## 基本使用

### 连接 B 站直播间

1. 右键系统托盘图标。
2. 点击 `连接B站直播间...`。
3. 输入直播间房间号。
4. 可选填写 B 站 Cookie。
5. 点击 `连接`。

填写 Cookie 后通常可以获取更完整的用户昵称和弹幕信息。

### 编辑模式

托盘菜单点击：

```text
→ 编辑模式 (调整大小/位置)
```

编辑模式用于调整弹幕幕布：

- 按住幕布中间拖动：移动整个幕布
- 拖动边缘：调整幕布大小
- 绿色虚线边框表示当前处于编辑模式

### 穿透模式

托盘菜单点击：

```text
→ 穿透模式 (默认)
```

穿透模式下幕布透明，并且鼠标可以穿过弹幕窗口操作后面的桌面、浏览器、游戏或其他软件。

### 切换模式

托盘菜单点击：

```text
切换 编辑/穿透 模式
```

该选项会在编辑模式和穿透模式之间切换。

## 弹幕设置

### 透明度

托盘菜单：

```text
弹幕透明度
```

支持从 `10%` 到 `100%` 的多个档位。

### 字体大小

托盘菜单：

```text
字体大小
```

支持小字号到大字号多个档位：

```text
8 / 9 / 10 / 11 / 12 / 13 / 14 / 15 / 16 / 18 / 20 / 22 / 24 / 26 / 28 / 32 / 36 / 40 / 48 / 56 px
```

### 弹幕速度

托盘菜单：

```text
弹幕速度
```

可选择：

```text
慢 / 中 / 快 / 极快
```

## 弹幕屏蔽

### 关键字屏蔽

托盘菜单点击：

```text
弹幕屏蔽关键字...
```

用法：

- 每行填写一个关键字
- 也可以用逗号或分号分隔
- 命中关键字的弹幕不会显示

示例：

```text
广告
刷屏
关键词1,关键词2
```

### 用户 ID 屏蔽

托盘菜单点击：

```text
ID弹幕屏蔽...
```

用法：

- 每行填写一个 B 站用户 ID
- 也可以用空格、逗号或分号分隔
- 命中用户 ID 的弹幕不会显示

示例：

```text
123456
987654
```

## HTML 字体标签

弹幕内容支持简单 HTML 字体标签，用于设置单条弹幕颜色和大小。

支持写法：

```html
<font color="red">你好</font>
<font color="#FF0000">红色弹幕</font>
<font color="yellow" size="40">黄色大字弹幕</font>
<font style="color:#00FFFF;font-size:36px">青色弹幕</font>
```

说明：

- 支持 `color`
- 支持 `size`
- 兼容 `style="color:...; font-size:...px"`
- 显示时会自动去掉 HTML 标签，只显示纯文本
- 字号限制在 `8-96`

当前不支持这种简写标签：

```html
<red>你好</red>
```

请使用：

```html
<font color="red">你好</font>
```

## 配置文件

程序会读取同目录下的配置文件：

```text
config.json
```

常见配置包括：

- 窗口位置和大小
- 弹幕字体大小
- 弹幕速度
- 弹幕透明度
- B 站房间号和 Cookie
- 屏蔽关键字
- 屏蔽用户 ID

注意：`config.json` 可能包含 B 站 Cookie，请不要上传到公开仓库。

## OBS 捕获说明

如果 OBS 使用 `游戏捕获` 或 `窗口捕获` 捕获游戏窗口，通常不会把 WanChat 一起捕获进去，因为 WanChat 是独立悬浮窗口。

如果 OBS 使用 `显示器捕获/屏幕捕获`，则会捕获整个屏幕，因此会把 WanChat 弹幕也录进去。

## 常见问题

### 鼠标无法操作后面的窗口

请确认当前处于 `穿透模式`。

### 无法移动幕布

请先切换到 `编辑模式`，然后按住幕布中间拖动。

### 白色弹幕在网页背景上看不清

当前版本已给弹幕文字加入轻微黑色描边。如果仍然不清楚，可以适当提高透明度或更换弹幕颜色。

### 弹幕没有显示

请检查：

- 是否已经连接直播间
- 房间号是否正确
- Cookie 是否有效
- 是否处于屏蔽关键字或用户 ID 命中状态
- 幕布是否被移动到屏幕外
